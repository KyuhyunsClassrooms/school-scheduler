학사일정 스케줄러 2.1 · 학교별 서버 연결

지원 환경: Windows 10 1809 이상 / Windows 11, Intel·AMD 64비트 PC

설치 완료 후 실행하면 바탕화면에 달력이 표시됩니다.
날짜를 클릭하면 선택되고, 두 번 클릭하면 해당 날짜의 메모를 편집합니다.
메모는 Ctrl+Enter 또는 바깥 클릭으로 저장합니다. Esc는 편집을 취소합니다.
위쪽 화살표 또는 마우스 휠로 월을 바꿉니다. 가운데 월 이름을 누르면 오늘로 돌아옵니다.
[목록] 또는 날짜의 오른쪽 클릭 메뉴로 개인 일정과 할 일을 추가·수정합니다.
할 일 패널은 오른쪽에 항상 표시됩니다. 창이 좁으면 달력 아래에 표시됩니다.
[+ 추가]로 할 일을 등록하고 체크박스로 완료 처리합니다. 제목을 두 번 클릭하면 수정·삭제합니다.
기한 없는 할 일도 표시합니다. 전체·오늘까지·중요 필터와 완료 포함 보기를 지원합니다.

학교에서 안내한 주소는 할 일 패널 아래 [학교 일정 연결]에서 입력합니다.
특정 학교나 중앙 서버에 자동 연결되지 않습니다. 어느 서버든 공통 JSON 규격이면 연결됩니다.
학교에서 읽기 토큰을 안내했다면 함께 입력하세요. 관리자 계정·Supabase secret key를 넣으면 안 됩니다.
시작할 때와 5분마다 자동 갱신합니다. 트레이 메뉴에서 즉시 새로고침할 수도 있습니다.
인터넷 연결이 끊기면 마지막 정상 일정을 유지합니다. 개인 메모와 할 일은 서버로 전송하지 않습니다.
기존 버전의 학교 일정은 로컬 데이터로 보존되며 서버 연결 후 해당 서버 일정으로 교체됩니다.

제목 막대를 끌어 이동하고 가장자리를 끌어 크기를 조절합니다.
작업표시줄 알림 영역의 아이콘 메뉴에서 위치 잠금, 투명도, 자동 실행을 설정합니다.

업데이트는 새 설치 파일을 실행하면 됩니다. 실행 중인 위젯은 먼저 정상 종료됩니다.
Windows 설정의 [설치된 앱]에서 [학사일정 스케줄러]를 선택해 제거할 수 있습니다.
설정과 사용자 데이터는 %LOCALAPPDATA%\SchoolScheduler에 남겨 재설치할 때 유지합니다.
개인 일정·할 일·메모는 calendar-data.json에 저장합니다.
별도 보관은 트레이 메뉴의 [백업 저장]을 이용하세요. 기존 JSON 백업도 가져올 수 있습니다.

이 버전은 WebView2나 브라우저를 사용하지 않습니다. 새 설치는 인터넷 없이 가능합니다.
