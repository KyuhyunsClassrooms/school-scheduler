# School Calendar Feed v1

자체 서버의 **최종 HTTPS URL**에 GET 요청했을 때 UTF-8 JSON 전체 스냅샷을 응답합니다. 앱은 특정 도메인·학교 ID·중앙 등록 서버에 의존하지 않습니다. 예시는 `examples/calendar.json`을 참고하세요.

```json
{
  "schemaVersion": 1,
  "name": "우리 학교 학사일정",
  "revision": "게시할-때마다-새로운-값",
  "updatedAt": "2026-10-24T09:00:00+09:00",
  "events": [
    {
      "id": "event-001",
      "start": "2026-10-26",
      "end": "2026-10-26",
      "title": "교직원 회의",
      "category": "교직원",
      "grades": "전체",
      "note": "회의실"
    }
  ]
}
```

| 항목 | 규칙 |
|---|---|
| `schemaVersion` | 필수 정수 `1`. 미지원 버전은 앱이 거부 |
| `name` | 필수 달력 이름, 1~100자 |
| `revision` | 필수 문자열 1~200자. **내용이 바뀔 때마다 변경**. UUID 권장. 숫자 대소 순서가 아닌 일치 여부로 비교 |
| `updatedAt` | 필수 ISO 8601 날짜·시간, 시간대 포함 권장 |
| `events` | 필수 배열. 최대 10,000건. 빈 배열은 모든 공유 일정을 지우는 정상 게시 |
| `id` | 각 일정의 고유 문자열, 1~200자. 수정 시 유지, 중복 금지 |
| `start`, `end` | 실제 존재하는 `YYYY-MM-DD`. 시작일·종료일 모두 포함, 종료 ≥ 시작. 주말도 표시 |
| `title` | 필수 제목 1~300자 |
| `category` | 선택, 최대 100자. `학교`, `수업 변경`, `평가`, `교직원`, `휴업·공휴일`, `창체`에 기본 색상. 다른 문자열도 가능 |
| `grades` | 선택, 최대 100자. 기본 `전체`. 학년 필터는 `1`, `2`, `3`, `1,2` 등 쉼표로 구분한 값 사용 |
| `note` | 선택 비고, 최대 20,000자 |

JSON 전체 응답은 UTF-8 **2MiB 이하**여야 합니다. HTML·JS·SQL은 실행하지 않습니다. 문자열은 텍스트로만 표시합니다.

## 전송·갱신

- 성공은 HTTP 200과 JSON 본문. 앱은 시작 시·5분마다 전체 목록을 받고 게시 revision이 바뀌면 교체합니다. 삭제도 스냅샷 교체에 반영됩니다.
- Content-Type은 `application/json; charset=utf-8`을 권장합니다.
- 앱은 `Accept: application/json`을 보냅니다. 읽기 토큰 설정 시 `Authorization: Bearer <token>`도 보냅니다.
- PC에 관리자 계정·DB 쓰기 키를 배포하지 않습니다. 앱의 읽기 토큰은 Windows 사용자 계정에 묶어 DPAPI로 암호화해 저장합니다. 개인 데이터 백업 JSON에는 포함하지 않습니다.
- 15초 제한, 응답 크기 제한, 필수 필드·날짜·중복 ID를 검증한 다음 캐시와 화면에 반영합니다. 4xx·5xx·네트워크 실패·형식 오류는 마지막 정상 일정을 유지합니다.
- **HTTP 3xx 리디렉션은 따라가지 않습니다.** 자격 증명의 다른 서버 전달을 막기 위함이며 최종 JSON 주소를 직접 입력하세요. 로그인 HTML 페이지나 Vercel 대시보드 주소는 일정 주소가 아닙니다.
- HTTPS 인증서를 검증합니다. 개발용 `http://localhost`, `http://127.0.0.1`, `http://[::1]`만 예외입니다.
- 실시간 push/WebSocket·증분 패치·iCalendar(ICS)·학교 이름 자동 검색은 v1 규격에 포함되지 않습니다.

## 정적 파일만으로 운영

DB 없이도 위 JSON 파일을 본인 HTTPS 호스팅에 올려 연결할 수 있습니다. 변경 시 새 revision을 넣고 파일 전체를 원자적으로 교체하세요. 앱 재배포는 필요하지 않습니다. 관리자 웹이 필요하면 함께 제공한 Vercel + Supabase 템플릿을 사용하면 됩니다.
